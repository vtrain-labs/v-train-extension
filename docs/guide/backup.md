# 備份與還原中心

V-Train 超級保護您的隱私！我們採用 **「零伺服器架構」**，這代表您的所有觀看紀錄、設定、還有私密的影片書籤，全部都只存在您的電腦裡，絕對不會上傳到任何網路雲端。
但也因為這樣，如果您的電腦壞了或是重灌瀏覽器，資料就會不見。所以，**定期備份非常重要喔！**

> ![備份與還原中心](/assets/manual/backup_center_main.png)

### 如何備份 (匯出資料)
打開控制面板，點擊底下的「**Export JSON (匯出)**」。
系統會非常貼心地幫您把所有的東西打包成一個 `ZIP` 壓縮檔，直接下載到您的電腦裡。
* **超強分塊打包技術**：如果您是一個超級收藏家，存了成千上萬張高畫質截圖，不用擔心備份時電腦會當機！V-Train 有內建「智能分塊打包技術」，會自動把大量的圖片切成一小塊一小塊的打包，保證備份過程順暢無比。

### 如何還原 (匯入資料)
換了新電腦？打開控制面板，點擊「**Import JSON (匯入)**」，系統會帶您進入還原中心頁面。
只要把您之前下載好的 `ZIP` 壓縮檔，輕輕拖曳到畫面中，放開滑鼠... 登愣！您所有的設定、心血結晶、還有那些漂亮的截圖封面，就會一秒鐘全部回來啦！
