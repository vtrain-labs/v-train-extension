# 書籤庫與互動面板

當您升級到 Pro 版，或是在看影片時，會發現畫面角落多了一些好用的小工具！

### 影片互動面板 (Hover Panel)
當您滑鼠移到影片上，右下角會浮現一個半透明的可愛面板。
> ![互動浮動面板](/assets/manual/floating_interaction_panel.png)
* **👍 喜歡 / 😤 不喜歡**：點一下，給這部影片打個分數吧！打完分數後，回到首頁看縮圖時，上面就會多一個小徽章提醒您這部片好不好看。
* **❤️ 收藏**：看到喜歡的影片？點下愛心，就能馬上把它收進您的「書籤庫」，還可以選要放進哪個資料夾喔！
* **📸 截圖封面**：有時候網站給的影片封面不好看。沒關係！看到最精采的畫面時，按一下這顆相機按鈕。系統會用最高清的方式幫您「喀嚓」截圖，把這個畫面變成您專屬的書籤封面！
* **📚 打開書籤庫**：點擊這本書，就能直接跳進您的專屬影片庫。

### 您的專屬書籤庫 (Bookmark Vault)
這是一個全螢幕的超美影片管理中心！
> ![書籤庫主畫面](/assets/manual/bookmark_vault_main.png)
* **無限資料夾管理**：您可以建立超多個資料夾，甚至資料夾裡面還能再包資料夾（就像電腦一樣）。對著資料夾點右鍵，就可以改名字或刪除。
* **聰明的防盜鏈機制 (動態 CDN 學習)**：有時候把影片加到書籤，過幾天封面圖片就不見了？別擔心！V-Train 有超強的防盜鏈學習技術，它會自動記住圖片的來源並幫您破解限制，確保您的封面永遠都看得到！
* **書籤隨意搬家**：把滑鼠游標移到影片卡片上，您就可以幫影片改個好記的名字、或是把它搬到別的資料夾。點一下卡片，就能馬上飛回影片的播放網頁！
