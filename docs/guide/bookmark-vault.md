# 4. 書籤庫與互動面板

### 影片互動面板
當您在觀看影片時，右下角會出現一個半透明的浮動面板。
> ![互動浮動面板](/assets/manual/floating_interaction_panel.png)
* **👍 喜歡 / 😤 不喜歡**：快速標記對這部影片的評價，評價會直接顯示在首頁的縮圖上。
* **❤️ 收藏**：將影片加入書籤庫，並可即時選擇要放入哪一個資料夾。
* **📸 截圖封面**：如果您覺得系統自動抓取的封面不好看，在播放到精彩畫面時點擊此按鈕，系統會使用 Canvas 原生技術無損擷取當前畫面作為專屬封面！

### 本機書籤庫 (Bookmark Vault)
> ![書籤庫主畫面](/assets/manual/bookmark_vault_main.png)
* **資料夾管理**：支援無限層級的子資料夾。您可以右鍵點擊資料夾進行「重新命名」、「移動」或「刪除」。
* **書籤操作**：將游標移至書籤卡片上，可以更改標題、移動到其他資料夾，或是點擊卡片直接跳轉回播放頁面。
