# 6. Pro 版進階功能

免費版使用者最多可儲存 200 筆觀看紀錄（達到上限時會自動替換最舊的紀錄）。升級至 **V-Train Pro** 即可享受無限制的儲存空間及以下專屬功能：
* 無限觀看紀錄與書籤儲存
* 解鎖完整的 Bookmark Vault (書籤庫) 管理系統
* 啟用影片互動面板 (按讚、截圖、快速收藏)
* 隱私密碼鎖設定 (Passcode)

### 如何啟用 Pro？
1. 在控制面板點擊下方的 **「⚡ Unlock V-Train Pro」**。
2. 貼上您購買時獲得的授權序號。
3. 驗證成功後，面板會顯示「V-Train Pro 已啟用」，並解鎖所有功能！

### 密碼忘記怎麼辦？ (救援解鎖)
如果您忘記了隱私密碼，點擊鎖定畫面的 **「Forgot Passcode?」**。
> ![密碼救援](/assets/manual/passcode_rescue.png)
輸入您的 Pro 授權序號進行驗證，成功後密碼將被重置並清除。建議解鎖後立即進行一次完整備份！
