# Pro 版進階功能

免費版已經很好用了，但如果您是個重度的影片愛好者，升級到 **V-Train Pro** 絕對會讓您愛不釋手！

### 免費版的小限制 (200 筆紀錄限制)
免費版的 V-Train 最多只能幫您記住 200 部影片的觀看進度。
不用擔心爆掉！系統有一個很聰明的「自動打掃機制 (Garbage Collection)」，當您看了第 201 部影片時，它會偷偷把您最久以前看的那一部紀錄刪掉，永遠保持最新的 200 筆。

### 升級 Pro 的三大超能力！
一旦您升級成為 Pro 玩家，就能解鎖以下超棒的功能：
1. **無限容量**：再也沒有 200 筆的限制，看多少存多少，自動打掃機制會立刻停工！
2. **解鎖超美書籤庫與面板**：您終於可以使用影片右下角的「浮動小面板」，瘋狂點愛心收藏影片、截取高畫質封面，並把它們通通收進全螢幕的「專屬書籤庫」裡，還能幫它們分類建資料夾喔！
3. **最高級的隱私密碼鎖**：您可以設定一組專屬密碼，以後任何人想打開 V-Train 看您的觀看紀錄，都得先過密碼這一關。

### 如何啟用 Pro？
1. 在控制面板最底下，點擊 **「⚡ Unlock V-Train Pro」**。
2. 把您買到的授權序號貼進去。
3. 系統會立刻連線驗證，成功後所有的功能就會瞬間解鎖！

### 忘記密碼怎麼辦？ (密碼救援)
哎呀，忘記自己設定的密碼了嗎？別緊張！
在輸入密碼的畫面點擊 **「Forgot Passcode?」**。
> ![密碼救援](/assets/manual/passcode_rescue.png)
只要輸入您的 Pro 授權序號，系統確認是您本人後，就會幫您把密碼重置。建議您解鎖後，立刻去備份一下資料喔！
