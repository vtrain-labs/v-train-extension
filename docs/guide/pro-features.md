## 📊 免費版的 200 筆紀錄限制

免費版的 V-Train 最多記錄 **200 部影片**的觀看進度。

### 自動清理機制（Garbage Collection）

當您看了第 **201** 部影片時，系統內建的「**垃圾回收機制 (GC)**」會自動啟動：

- 自動找出**最久沒有更新過**的那一筆進度紀錄
- 靜悄悄地把它刪掉，騰出空間
- 永遠保持最新的 200 筆

> 😅 這就像一個只能記 200 件事的小機器人，當你教他第 201 件事時，他就必須忘記最久以前學的那件事。

::: tip 💡 書籤保護
如果您有使用 Pro 版的書籤功能，並將某部影片加入書籤庫，那麼即使是免費版的 GC 機制，也**絕對不會刪除**有書籤保護的影片紀錄。  
這是因為書籤代表「這部影片很重要」，系統會自動貼上護身符！
:::

::: info 什麼時候會感受到 200 筆限制？
- 您是輕度使用者（偶爾看幾部）→ 幾乎感受不到
- 您是**重度使用者**（每天看大量影片）→ 較舊的紀錄會被清除
- 您想要**永久保存所有進度** → 升級 Pro 版！
:::

## 🎯 Pro 版三大超能力

### ① 無限影片紀錄容量

升級 Pro 後，200 筆的上限**立刻解除**，GC 機制隨即**永久停工**。  
您可以無限制地記錄所有影片的觀看進度，永不遺忘。

### ② 浮動互動面板（Hover Panel）

當您在影片**播放頁面**上，画面上會浮現一個精美的操作面板：

> ![浮動互動面板](/assets/manual/22.png)

**面板功能說明：**

| 按鈕 | 功能 |
|-----|------|
| 👍 喜歡 | 給這部影片標記「喜歡」，縮圖上出現大拇指朝上徽章 |
| 👎 不喜歡 | 給這部影片標記「不喜歡」，縮圖上出現大拇指朝下徽章 |
| ❤️ 收藏 | 開啟資料夾選擇器，將影片加入書籤庫 |
| 📸 截圖 | 擷取當前最佳畫面作為自訂封面 |
| 📚 書籤庫 | 直接跳轉到您的個人書籤庫 |

::: tip 💡 面板位置可以拖動！
覺得面板出現的位置不順手？用滑鼠拖動面板，系統會記住您的自訂位置，下次自動出現在相同地方。
:::

::: info 想暫時關閉浮動面板？
只需到**控制面板**，把「**互動面板開關 (Hover Panel)**」關掉，下次需要時再開啟即可。
:::

### ③ 書籤庫（Bookmark Vault）

全螢幕的個人影片管理中心！詳細說明請參閱 [書籤庫與互動面板](./bookmark-vault) 頁面。

### ④ 截圖自訂封面

在影片最精彩的畫面，點擊面板上的 📸 截圖按鈕：

1. 系統嘗試從影片的 `<video>` 元素或 `<canvas>` 擷取當前畫面
2. 若直接擷取失敗，自動嘗試從頁面的 `og:image` 或 `twitter:image` Meta 標籤獲取圖片
3. 圖片壓縮為 **320px 寬的 WebP 格式**，儲存到本地 IndexedDB
4. 成功後，書籤庫中這部影片的封面會立刻更新為您截取的畫面

::: warning ❌ 什麼情況下截圖會失敗？
- 影片藏在深層的 `<iframe>` 中（跨網域限制）
- 網站有嚴格的 CORS / CSP 安全政策
- 截圖按鈕上出現紅色 ❌ 圖示代表截圖失敗

即使截圖失敗，影片仍然可以正常收藏到書籤庫，只是使用原本的封面圖。
:::

### ⑤ 隱私密碼鎖（Passcode Protection）

Pro 版允許您為 V-Train 設定一組專屬密碼：

- 設定後，每次點擊 V-Train 圖示都需要**先輸入密碼**
- 密碼保護的是「控制面板」的訪問權限，阻止他人偷看您的觀看紀錄
- 輸入正確密碼後，在關閉面板前不需要重複輸入

> ![密碼鎖畫面](/assets/manual/32.png)

## 🔑 如何啟用 Pro？

1. 前往 [V-Train Pro 購買頁面](https://v-train.lemonsqueezy.com/checkout/buy/3dbcb93a-052c-433c-9adb-5fdcf221cc17)（一次性買斷，無訂閱費）
2. 完成付款後，您會收到一組**授權序號（License Key）**
3. 開啟 V-Train **控制面板**，找到底部的「**⚡ 解鎖Pro(Unlock V-Train Pro)**」按鈕
4. 點擊按鈕，將授權序號貼入輸入框
5. 系統連線驗證（需要網路）
6. 驗證成功後，所有 Pro 功能**立刻解鎖**！

> ![Pro 啟用按鈕](/assets/manual/33.png)

::: tip 💡 授權序號要保管好！
您的授權序號可以在需要時重新使用（例如換電腦）。建議把序號記錄在安全的地方，例如密碼管理器或記事本中。
:::

## 🆘 忘記密碼怎麼辦？

如果您設定了密碼鎖但忘記密碼，請按照以下步驟救援：

> ![忘記密碼按鈕](/assets/manual/17.png)

1. 在密碼輸入畫面，點擊 **「忘記密碼(Forgot Passcode?)（忘記密碼）」**連結
2. 系統會要求您輸入 **Pro 授權序號**作為身份驗證
3. 輸入正確的序號後，密碼將被重置
4. 重置後，建議立刻**設定一個新密碼**並**備份資料**

::: danger 💀 如果忘記密碼且找不到授權序號
很遺憾，在這種情況下無法重置密碼。這是為了**最大化保護您的隱私**所做的設計決策。  
唯一的解決方案是重新安裝 V-Train（**將清除所有資料**），然後重新購買 Pro 版。  
**請務必妥善保存您的授權序號！**
:::
