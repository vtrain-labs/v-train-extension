# 快速上手 (安裝與使用)

歡迎來到 V-Train！這是一個能讓您在看影片時超級開心的神奇小工具！

### 第一步：安裝與開啟
1. 從 Chrome 線上應用程式商店安裝好 V-Train 後，點擊瀏覽器右上角的拼圖圖案，把 V-Train 釘選出來。
2. 點擊 V-Train 圖示，就會跳出我們的 **控制面板 (Dashboard)**！

### 第二步：授權給您喜歡的網站
1. 當您去到一個想看影片的網站時，打開 V-Train 的控制面板。
2. 點擊面板右上角的 **「Authorize & Enable Current Site (授權並啟用當前網站)」** 按鈕。
   > ![授權按鈕](/assets/manual/btn_authorize.png)
3. 點選允許之後，V-Train 就會開始在這個網站上努力工作囉！如果我們已經認識這個網站，您馬上就會在影片的圖片底下看到**紅色的觀看進度條**了！就這麼簡單！
