# 🚀 快速上手：安裝與首次設定

歡迎來到 V-Train！這份指南會手把手帶您完成從「零」到「看影片就有進度條」的全部流程，大概只需要 3 分鐘！

::: info 💡 V-Train 是什麼？
V-Train 是一個 Chrome 瀏覽器擴充功能，能在您瀏覽影音網站時，自動在每部影片的縮圖底下顯示**紅色觀看進度條**，就像 YouTube 那樣！完全本地運作，零資料上傳。
:::

---

## 一、安裝方式

### ✅ 方法 A：從 Chrome 線上應用程式商店安裝（推薦）

這是最簡單、最安全的方式，適合所有人。

1. 點擊下方連結前往 Chrome 線上應用程式商店：

   **[👉 前往安裝 V-Train](https://chromewebstore.google.com/detail/v-train-adaptive-video-ba/cikabjkegiefjgalfncfoehmkpmkoiaf)**

2. 點擊頁面右上角藍色的「**加到 Chrome**」按鈕。

   > ![Chrome 商店安裝頁面](/assets/manual/1.png)

3. 彈出確認視窗後，點擊「**新增擴充功能**」。

4. 安裝完成後，Chrome 右上角會出現 V-Train 的圖示（一個深色的 VT 標誌）。

::: tip 🎉 安裝成功的確認方式
如果右上角有出現 V-Train 圖示，代表安裝成功！如果沒看到，請繼續看下面「釘選擴充功能」的步驟。
:::

---

### 🔧 方法 B：手動安裝（開發者模式）

如果您是從 GitHub 下載了原始碼、或是想測試尚未上架的版本，可以用開發者模式手動載入。

::: warning ⚠️ 注意
此方法適合進階使用者。從不明來源下載的擴充功能請務必謹慎，確認來源可信後再安裝。
:::

1. 下載並解壓縮 V-Train 的原始碼資料夾到您電腦的某個位置。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
3. 點擊右上角的**「開發人員模式」**開關，將其打開。

   > ![開啟開發人員模式](/assets/manual/2.png)

4. 點擊左上角出現的**「載入未封裝項目」**按鈕。
5. 在跳出的資料夾選擇視窗中，選取您剛才解壓縮的 V-Train 資料夾（裡面應該有 `manifest.json` 這個檔案）。
6. 點擊「選取資料夾」，V-Train 就會出現在您的擴充功能清單中了！

::: info 📌 開發者模式小提醒
以開發者模式載入的擴充功能，每次重啟 Chrome 後可能會跳出「停用開發者模式擴充功能」的警告，點擊「取消」即可繼續正常使用。
:::

---

## 二、釘選擴充功能（讓圖示常駐工具列）

安裝好之後，Chrome 預設會把新擴充功能「收起來」。為了方便每次使用，我們需要把 V-Train「釘出來」！

1. 點擊 Chrome 工具列右上角的**拼圖圖案 🧩**（擴充功能按鈕）。

   > ![點擊拼圖圖案](/assets/manual/3.png)

2. 在跳出的清單中，找到 **V-Train Adaptive Video**。
3. 點擊右邊的**圖釘圖示 📌**，讓它變成藍色的「已釘選」狀態。

   > ![釘選 V-Train 圖示](/assets/manual/4.png)

4. 完成！現在 V-Train 的 VT 圖示應該會永遠顯示在工具列上了。

::: tip 快速小技巧
如果您用的是 Edge 瀏覽器（也支援 Chrome 擴充功能），操作方式完全相同，一樣找工具列的拼圖圖案就可以了！
:::

---

## 三、首次啟動：開啟控制面板

釘選完成後，就可以正式啟動 V-Train 了！

1. **點擊工具列上的 VT 圖示**。
2. 一個黑色主題的**控制面板（Dashboard）**就會從圖示下方彈出！

   > ![V-Train 控制面板主畫面](/assets/manual/5.png)

這個面板就是 V-Train 的「指揮中心」，所有設定都在這裡操控。



---

## 四、授權網站：必做的第一件事！

V-Train 採用「**按需授權**」的方式，您需要主動告訴它「我允許你在這個網站上工作」。這是為了保護您的隱私——V-Train 不會在沒有您明確許可的網站上偷偷執行任何東西。

這個步驟**必須在每一個想要使用 V-Train 的網站上各做一次**。

### 步驟如下：

1. 先打開您想追蹤進度的影音網站（例如：某部影片的首頁列表頁）。
2. 點擊工具列的 VT 圖示，**開啟 V-Train 控制面板**。
3. 點擊面板**最上方**藍色的 **「授權並啟用(Authorize & Enable Current Site)」** 按鈕。

   > ![授權按鈕](/assets/manual/6.png)

4. Chrome 會彈出一個系統確認視窗，詢問「是否要允許這個擴充功能讀取此網站的資料？」— 點擊**「允許」**。

5. 授權完成後，按鈕的顏色會變成**綠色**，顯示「✅ 已授權(Site Authorized)（已授權）」。

   > ![授權成功狀態](/assets/manual/7.png)

6. 如果這個網站已經有內建的規則，**重新整理一下頁面**，您馬上就會在影片縮圖下方看到**紅色進度條**出現！

::: warning ⚠️ 授權後沒有進度條？別擔心！
看到授權成功，但進度條還是沒出現？這很正常！這代表 V-Train 尚未「認識」這個網站。您需要用「適應引擎」來訓練它。請參考 [適應引擎訓練指南](./adaptive-engine.md)。
:::

## 五、關於預設的「手動暫停(Monitoring Off)」模式

您可能會發現，剛安裝好 V-Train 後，明明已經授權了某個網站，但還是看不到進度條？

這是因為 V-Train 在**第一次安裝時，預設會開啟「手動暫停(Monitoring Off)」模式**。

### 什麼是手動暫停(Monitoring Off)模式？

想像一下，您偶爾想要「暫停追蹤」，不想讓 V-Train 記錄這次觀看。這時候，切換到手動暫停(Monitoring Off)就像是把 V-Train 暫時「關掉」——它不會顯示進度條，也不會記錄您的觀看進度！

**預設開啟手動暫停(Monitoring Off)**的設計，是為了讓您在安裝後有機會先熟悉面板，不會一安裝就立刻開始記錄您的一切行為。

### 如何切換到「自動監控(Monitoring)」、正式開始追蹤？

1. 打開 V-Train 控制面板。
2. 找到最頂部的「**狀態開關**」，它目前顯示灰色指示燈的「**手動暫停(Monitoring Off)**」。
3. **點擊這個開關**，讓它切換成綠色指示燈的「**🟢 自動監控(Monitoring)**」狀態。

   > ![監控開關](/assets/manual/8.png)

4. 開關變綠之後，就代表 V-Train 開始正式工作囉！**重新整理頁面**，進度條就會出現了！

::: tip 💡 小技巧：想要隨時暫停？
兩個模式可以隨時切換！當您不想被記錄時，把開關切回「手動暫停(Monitoring Off)」；想繼續追蹤時，再切回「自動監控(Monitoring)」。操作非常彈性！
:::

## 六、無痕模式注意事項

V-Train 的 manifest 設定支援無痕模式（`"incognito": "spanning"`），但您需要手動開啟此權限。

::: warning ⚠️ 預設情況下，無痕視窗不可用
Chrome 出於安全考量，預設**不允許**任何擴充功能在無痕視窗中執行。如果您在無痕模式下打開 V-Train，可能會看到警告提示。
:::

### 如何允許 V-Train 在無痕模式中使用？

1. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
2. 找到 **V-Train Adaptive Video** 並點擊「**詳細資料**」。
3. 在詳細資料頁面，找到「**在無痕式視窗中允許**」選項。
4. 點擊旁邊的開關，將其打開。

   > ![允許無痕模式](/assets/manual/9.png)

開啟後，V-Train 就可以在無痕視窗中正常執行了！

::: info 📌 無痕模式下的隱私行為
即使在無痕模式中啟用了 V-Train，您仍然可以隨時切換到「手動暫停(Monitoring Off)」來停止記錄。兩種隱私保護機制可以搭配使用。
:::

## 七、常見安裝問題 Q&A

### ❓ Q：安裝後找不到 V-Train 圖示怎麼辦？

請依照本頁「二、釘選擴充功能」的步驟，點擊工具列的拼圖圖案，手動將 V-Train 釘出來即可。

---

### ❓ Q：點擊授權按鈕後，Chrome 沒有彈出任何確認視窗？

這可能是因為您目前所在的頁面是 `chrome://` 開頭的系統頁面、或是本機的 `file://` 頁面。V-Train 只能在正常的 `http://` 或 `https://` 網頁上進行授權。請先前往您想使用的影音網站，再嘗試授權。

---

### ❓ Q：已經授權了，為什麼網站還是沒有進度條？

請依序確認以下幾點：

1. ✅ 確認控制面板的狀態開關是「🟢 自動監控(Monitoring)」，而不是「手動暫停(Monitoring Off)」。
2. ✅ 確認授權按鈕已變成綠色的「已授權」狀態。
3. ✅ 重新整理頁面後再看看。
4. 如果以上都確認過了，進度條還是沒出現——這個網站目前可能還沒有 V-Train 的內建規則。您可以使用[適應引擎](./adaptive-engine.md)自己訓練，或到[社群規則庫](https://github.com/vtrain-labs/community-rules)查看是否有人已經分享了這個網站的規則。

---

### ❓ Q：控制面板打開後顯示的是英文，我想換成中文？

在面板頂部的右上方有一個**語言選單（Language）**，點開後選擇「繁體中文」即可。語言設定會即時生效！

---

### ❓ Q：擴充功能可以在 Microsoft Edge 上使用嗎？

可以！Microsoft Edge 完全支援 Chrome Web Store 的擴充功能。您可以直接用 Edge 前往 Chrome 線上應用程式商店安裝 V-Train，操作方式與 Chrome 完全相同。

::: danger 🚫 不支援的瀏覽器
V-Train 目前僅支援基於 Chromium 核心的瀏覽器（Chrome、Edge、Brave 等）。Firefox 及 Safari 目前**不支援**。
:::
