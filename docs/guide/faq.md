# ❓ 常見問題 (FAQ)

遇到怪問題嗎？先看看這裡有沒有解答！找不到答案再去 [GitHub Issues](https://github.com/vtrain-labs/v-train-extension/issues) 回報。

---

## 🔴 進度條相關問題

### Q：為什麼我在某個影片網站上看不到紅色進度條？

**可能原因與解法（依序排查）：**

1. **沒有授權這個網站**  
   → 打開控制面板，點擊 **「授權並啟用(Authorize & Enable Current Site)」** 按鈕

2. **V-Train 不認識這個網站**  
   → 如果授權後還是沒出現，這個網站需要手動訓練。請去使用[適應引擎](./adaptive-engine)訓練它！

3. **目前是「手動暫停(Monitoring Off)」模式**  
   → ✅ 確認控制面板的狀態開關是「🟢 **自動監控(Monitoring)**」，而不是「**手動暫停(Monitoring Off)**」。

4. **您在影片播放頁（不是列表頁）**  
   → V-Train 的進度條顯示在**影片縮圖列表**上。在播放頁面看不到是正常的，請回到列表頁確認。

5. **網頁需要重新整理**  
   → 授權後若沒有立刻出現進度條，請按 **F5** 重新整理網頁。

---

### Q：為什麼有些影片的進度條消失了？（免費版限制）

::: warning 免費版 200 筆上限
免費版最多記錄 **200 筆**影片進度。當超過 200 筆時，系統會自動刪除最久沒更新的紀錄。  
若要永久保存所有進度，請升級 [Pro 版](./pro-features)。
:::

如果是 Pro 版用戶，進度消失可能是您不小心清除了資料，或是備份還原時出錯，建議定期備份。

---

### Q：進度條的顏色怎麼改？

打開控制面板，找到 **「Progress Bar Color（進度條顏色）」** 的色塊，點擊它就能開啟顏色選擇器，選擇您喜歡的任何顏色！

## 🖼️ 截圖相關問題

### Q：為什麼截圖按鈕上出現紅色 ❌？

V-Train 使用了多種技術嘗試截圖，但某些情況下仍然會失敗：

::: warning 常見的截圖失敗原因
- **跨域 `<iframe>`**：影片被嵌套在來自不同網域的 iframe 裡（常見於嵌入式播放器）
- **嚴格的 CORS/CSP 政策**：網站設定了阻止截圖的安全標頭
- **CANVAS 繪製受限**：某些使用 DRM 保護的影片無法透過 canvas 截圖
:::

截圖失敗不影響其他功能。您仍然可以：
- 把影片加入書籤（使用原本的封面）
- 繼續追蹤觀看進度

---

### Q：我之前截取的封面圖消失了，怎麼辦？

截圖封面儲存在瀏覽器的 **IndexedDB** 中。如果您有過下列操作，封面圖會消失：
- 移除並重新安裝擴充功能
- 清除瀏覽器儲存資料

::: tip 💡 如何防止這個問題？
定期到控制面板執行**匯出備份（Export Full Backup）**，選擇「含截圖封面」選項，這樣您的封面圖就會一起被打包到 ZIP 備份中！
:::

## 📕 書籤庫相關問題

### Q：書籤庫的封面圖過幾天就不見了，怎麼辦？

這是「CDN 防盜鏈」問題，非常常見！  
許多影片網站的封面圖使用 CDN 服務，這些 CDN 會检查請求的來源（Referer），如果來源不對就拒絕顯示。

V-Train 有內建**動態防盜鏈學習引擎**：

> 每次您開啟書籤庫時，系統會掃描所有書籤的封面 URL，自動找出 CDN 網域，並請 `background.js` 建立動態的 `declarativeNetRequest` 規則，偽裝成正確的 Referer 標頭，讓圖片重新顯示。

::: tip 💡 解決步驟
1. 關閉並重新開啟書籤庫頁面
2. 等待幾秒讓防盜鏈引擎運作
3. 若圖片還是不顯示，嘗試重新截圖（用 📸 截圖功能），這樣圖片就直接存在本地，完全不受防盜鏈影響！
:::

---

### Q：我不小心刪除了一個書籤，能復原嗎？

很遺憾，書籤刪除後**無法直接復原**（除非您有備份）。  
這是因為 V-Train 採用零伺服器架構，沒有「回收站」或「雲端備份」功能。

::: warning 建議
- 在刪除大量書籤前，先做一次**備份（Export）**
- 可以把重要的書籤放在特定資料夾，避免誤刪
:::

## 🔐 密碼與隱私問題

### Q：我忘記自己設定的密碼了！

請參閱 [Pro 版進階功能](./pro-features#忘記密碼怎麼辦) 的「忘記密碼救援」部分。

簡要步驟：在密碼輸入畫面點擊 **「忘記密碼(Forgot Passcode?)」** → 輸入您的 **Pro 授權序號** → 密碼重置。

---

### Q：V-Train 有沒有把我的資料上傳到任何地方？

**絕對沒有。** V-Train 採用「零伺服器架構」：

- 所有觀看紀錄、書籤、規則都只存在您的**本機瀏覽器**中
- 唯一的網路請求是 Pro 版**授權序號驗證**（僅傳送序號本身，不包含任何個人資料）
- V-Train **沒有自己的資料庫伺服器**

您可以透過 Chrome 開發者工具的「網路」分頁自行驗證這一點。

---

### Q：如果我移除 V-Train，我的資料還在嗎？

**不在了！** 移除擴充功能時，瀏覽器會一併清除該擴充功能的所有本地儲存資料，包含：
- IndexedDB 中的所有影片紀錄、書籤、截圖封面
- chrome.storage.local 中的所有設定

::: danger ⚠️ 移除前請先備份！
如果您有珍貴的書籤或截圖，在移除前請務必先執行**匯出備份（Export Full Backup）**！
:::

## 🌐 適應引擎問題

### Q：我訓練好了，但影片縮圖上還是沒有出現進度條？

請依序排查：

1. **確認訓練網站有被授權**：控制面板 → 授權當前網站
2. **重新整理頁面**：F5 或 Ctrl+R
3. **確認 Mod 存入了正確位置**：控制面板 → 已訓練網站，確認有看到這個網站的規則
4. **確認框框選對了**：訓練時應該選擇「包住縮圖的容器 div」，不能選圖片本身（IMG 標籤）

若以上都沒問題，可能是這個網站的 URL 結構比較特殊。嘗試刪除舊規則，重新訓練，這次嘗試點擊 URL 中不同的分段作為 ID。

---

### Q：我的朋友給了我一個 VT-RULE-Z... 序號，怎麼匯入？

1. 開啟控制面板
2. 點擊 **「已訓練網站（已訓練網站(Trained Sites)）」** 按鈕
3. 在規則管理頁面，找到「匯入規則序號」輸入框
4. 貼上 `VT-RULE-Z...` 序號，點擊確認
5. 匯入成功後，此規則立刻生效！

## ⚡ 效能問題

### Q：V-Train 會讓我的瀏覽器變慢嗎？

V-Train 的設計非常注重效能：

- 使用 **IntersectionObserver** 只追蹤畫面上可見的縮圖，不掃描整個 DOM
- 使用 **MutationObserver** 偵測頁面動態新增的元素，並做節流（debounce）
- 進度條繪製使用 **requestAnimationFrame** 批次處理，避免 Layout Thrashing
- 背景腳本使用節流鎖，防止高頻事件爆炸

在一般使用情況下，對瀏覽器效能的影響**幾乎可以忽略**。

---

### Q：我同時開了很多書籤庫分頁，資料會不同步嗎？

不會！V-Train 使用了 **BroadcastChannel API (`vt_sync_channel`)** 在所有開啟的書籤庫分頁之間即時同步。  
當您在一個書籤庫分頁新增或刪除書籤，其他所有分頁都會自動更新，無需手動重新整理。

## 🔔 無痕模式問題

### Q：V-Train 在無痕模式下可以用嗎？

可以，但需要額外設定：

1. 在 Chrome 網址列輸入 `chrome://extensions/`
2. 找到 V-Train，點擊**「詳細資料」**
3. 開啟**「在無痕視窗中啟用」**選項

::: info 無痕模式的注意事項
V-Train 的 manifest 設定了 `"incognito": "spanning"`，這表示在無痕模式下，V-Train 的資料與一般模式**共用**，不是分開的資料庫。  
在無痕視窗看過的影片，進度紀錄同樣會被記錄下來。
:::
