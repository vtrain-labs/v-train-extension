# 7. 常見問題 (FAQ)

**Q: 為什麼進度條沒有顯示出來？**  
A: 請先確認您是否已點擊了「授權並啟用當前網站」。如果已授權仍未顯示，可能是該網站尚未建立規則，您可以使用「適應引擎」手動訓練它。

**Q: 為什麼截圖功能會顯示紅色的 ❌？**  
A: 某些網站的影片被多層 `iframe` 深度嵌套，或是受到跨域安全 (CORS) 限制。我們已經內建了穿透引擎，但極少數受到嚴格內容安全策略 (CSP) 保護的影片仍可能無法截圖。

**Q: 移除擴充功能後，我的資料還在嗎？**  
A: **不在！** 為了絕對的隱私安全，V-Train 不會將資料上傳到任何雲端。移除擴充功能會一併清空瀏覽器本地資料庫。請務必善用「備份與還原」功能保存您的 ZIP 備份檔。
