# 常見問題 (FAQ)

遇到奇怪的問題嗎？先看看這裡有沒有解答！

**Q: 為什麼縮圖上沒有出現紅色的進度條？**
A: 首先，請打開控制面板，確定您已經點了「授權並啟用當前網站」。如果還是沒有，可能是這個網站 V-Train 還不認識。趕快去使用「適應引擎」手動訓練它吧！

**Q: 為什麼有時候我按「截圖」按鈕，它會出現紅色的 ❌？**
A: 這通常是因為網站把影片藏在很深的防護罩 (iframe) 裡面，或是網站有很嚴格的安全限制 (CORS / CSP)。V-Train 其實已經內建了很強的「穿透技術」去嘗試截圖了，但如果真的遇到防護太嚴密的網站，也是會踢到鐵板的。

**Q: 我如果不小心把擴充功能刪掉了，我的資料還在嗎？**
A: **不在了喔！** 為了絕對保護您的隱私，V-Train 絕對不偷傳資料到雲端。所以一旦您移除擴充功能，瀏覽器就會把所有的紀錄清空。**千萬要記得定期去「備份與還原中心」下載備份檔 (ZIP) 保平安！**

**Q: 免費版的自動刪除 (GC) 會不會把我收藏的影片也刪掉？**
A: 絕對不會！如果您已經把這部影片加到「書籤庫」裡了，系統就會幫它貼上護身符，打掃機制是絕對不會碰它的。
