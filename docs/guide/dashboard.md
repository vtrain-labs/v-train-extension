# 2. 控制面板詳解

V-Train 的控制面板是您管理所有設定的核心樞紐。

> ![控制面板主畫面](/assets/manual/dashboard_main.png)

### 狀態監控區
* **自動監控 (Monitoring) / 手動暫停 (Stealth)**：
  > ![監控開關](/assets/manual/toggle_monitoring.png)
  透過開關可以隨時暫停 V-Train 的追蹤功能。開啟「關閉瀏覽器即自動暫停」可在您離開時保護隱私。
* **啟用快捷互動按鈕**：控制影片畫面右下角是否要顯示「按讚/收藏/截圖」的懸浮面板。
* **Show Monitor Panel**：決定是否在網頁左下角顯示 V-Train 的系統狀態小黑窗。
* **進度條顏色 (Progress Bar Color)**：點擊色塊可以自由更改您喜歡的進度條顏色（預設為紅色）。

### 捷徑與管理區
* **已訓練網站 (規則管理)**：
  > ![規則管理按鈕](/assets/manual/btn_rule_mgmt.png)
  管理您自訂或匯入的網站適應規則。可以在這裡刪除不需要的規則，或是將規則「複製序號」分享給其他人。
* **Bookmark Vault (書籤庫)**：`[Pro 限定]` 進入全螢幕的書籤管理中心。
* **設定密碼 / 清除資料**：
  > ![隱私設定](/assets/manual/btn_privacy_settings.png)
  設定專屬的隱私密碼鎖。每次開啟面板時需輸入密碼才能查看數據。點擊「清除資料」可一鍵刪除所有本地觀看紀錄與書籤（不影響 Pro 狀態與規則）。
