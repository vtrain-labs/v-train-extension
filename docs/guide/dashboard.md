# 控制面板 (Dashboard) 詳解

V-Train 的控制面板就像是您的「指揮中心」，所有的開關跟設定都在這裡！

> ![控制面板主畫面](/assets/manual/dashboard_main.png)

### 狀態與開關
* **暫停監控 (Stealth Mode)**：
  > ![監控開關](/assets/manual/toggle_monitoring.png)
  如果您今天想悄悄看影片，不想留下任何進度紀錄，可以點擊右上角的開關進入「**Stealth Mode (潛行模式)**」。所有的進度條都會暫時隱藏起來喔！
* **懸浮面板開關 (Hover Panel)**：看影片時，右下角彈出來的那個小框框（可以按讚、截圖、收藏的面板），如果您覺得礙眼，可以在這裡把它關掉。
* **除錯小黑窗 (Monitor Panel)**：如果您想知道系統現在抓到了哪個影片 ID、是不是在錄製中，可以打開這個小黑窗，它會出現在畫面的左下角。
* **進度條顏色 (Progress Bar Color)**：覺得預設的紅色進度條看膩了？點一下顏色方塊，換成您喜歡的專屬顏色吧！
* **語言切換 (Language)**：控制面板的文字看不懂嗎？最底下有語言選單，可以隨時切換成中文或英文！

### 捷徑與隱私設定
* **已訓練網站 (Trained Sites)**：
  > ![規則管理按鈕](/assets/manual/btn_rule_mgmt.png)
  您自己訓練好的網站、或是跟朋友拿來的「規則序號 (VT-RULE)」，都在這裡管理。可以刪除不要的，或是複製序號分享給別人。
* **書籤庫 (Bookmark Vault)**：`[Pro 版限定]` 點進去就會開啟一個全螢幕的漂亮大書櫃，管理您收藏的所有影片！
* **密碼鎖定 / 清除資料**：
  > ![隱私設定](/assets/manual/btn_privacy_settings.png)
  想要絕對的隱私？您可以設定一組「密碼鎖 (Passcode)」。設定好之後，每次打開這個指揮中心都要先輸入密碼！如果想把所有觀看紀錄一鍵刪光光，點擊「Clear Data (清除資料)」就可以了。
