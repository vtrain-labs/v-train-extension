# 適應引擎 (Adaptive Engine)：訓練新網站

如果遇到 V-Train 還不認識的影音網站（也就是沒有出現進度條），別擔心！您可以親自「訓練」它，讓它學會怎麼在這個網站上運作！

> ![訓練模式概覽](/assets/manual/training_mode_overview.png)

### 訓練步驟大揭密：
1. **啟動引擎**：在網站首頁，對著**任何一個影片的縮圖點擊「右鍵」**，然後在左下角 V-Train 的小黑窗裡面，選擇要存入的模組 (Mod 1 ~ Mod 4)。
2. **用框框抓住它 (Visual Capture)**：
   > ![視覺化捕捉框](/assets/manual/visual_capture_box.png)
   畫面上會出現一個綠色（或紅色）的選取框。
   * 用鍵盤的 **`↑` (上) / `↓` (下)** 鍵，可以把框框放大或縮小。
   * 請確認框框**剛好包住整張圖片**！如果是青色框框代表很完美，如果是紅色框框代表抓錯地方囉。
   * 抓好之後，按下 **`Enter`** 確定。
3. **貼上影片網址**：點一下剛才抓的圖片，進去影片播放頁面。把上面網址列的「完整網址」複製下來，貼到 V-Train 的框框裡。
4. **告訴它誰是 ID**：V-Train 很聰明，它會自動把網址切成好幾塊。您只要點擊那塊看起來最像「這部影片唯一身分證號碼」的英數字組合就好！（不管網址是用 `?v=`、斜線 `/`、甚至是自訂的底線 `_` 分隔，它都能學會）。
   > ![綁定ID](/assets/manual/bind_id.png)
5. **完成訓練**：點擊儲存！現在回到首頁，您就會發現這個網站所有的影片，通通都長出紅色的進度條啦！

### 把您訓練的成果分享給別人 (分享規則序號)
訓練好一個網站後，覺得自己很厲害想分享給朋友嗎？
去「控制面板」裡的「已訓練網站」，點擊複製按鈕。您會得到一串像是 `VT-RULE-XXXX...` 的神秘代碼。只要請您的朋友把這串代碼貼進他的 V-Train 裡面，他就能立刻擁有您辛苦訓練的成果喔！
