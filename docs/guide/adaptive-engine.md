# 3. 適應引擎：訓練新網站

如果遇到 V-Train 無法自動識別的影音網站，您可以透過獨家的「適應引擎 (Adaptive Engine)」親自訓練它！

> ![訓練模式概覽](/assets/manual/training_mode_overview.png)

### 訓練步驟：
1. **啟動引擎**：在目標網站上，對著**任何一個影片縮圖點擊「右鍵」**，然後在左下角的 V-Train 面板選擇要存入的模組 (Mod 1 ~ Mod 4)。
2. **視覺化捕捉 (Visual Capture)**：
   > ![視覺化捕捉框](/assets/manual/visual_capture_box.png)
   畫面會出現一個綠色或紅色的選取框。
   * 使用鍵盤的 **`↑` (上) / `↓` (下)** 鍵來擴張或縮小選取範圍。
   * 請確保選取框**剛好包覆住整張縮圖圖片**，不要選到外層的文字標題。
   * 調整完畢後按下 **`Enter`** 確認。
3. **輸入正片網址**：點擊該縮圖進入播放頁面，將網址列的完整 URL 複製並貼上到 V-Train 面板中。
4. **綁定 ID**：系統會分析網址並列出可能的 ID 片段。請點選最像「影片唯一編號」的那一段。
   > ![綁定ID](/assets/manual/bind_id.png)
5. **完成訓練**：點擊儲存，現在回到首頁，您就會發現該網站的所有影片都已經成功掛上進度條了！
